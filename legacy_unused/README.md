# Legacy Unused Code Archive

This directory contains legacy, unused, and unwired components, pages, and utility modules from earlier iterations of the SonoDS project.

> [!NOTE]
> None of the files in this directory are imported by or active in the current application shell. They are preserved here for historical reference or potential future feature revival.

## Directory Map

- **`components/`**: Legacy standalone React UI components (`MixComparator.js`, `HolographicWaveform.js`, `SmartFader.js`, `CareerMode.js`, `CharacterModal.js`, etc.).
- **`pages/`**: Legacy page-level views (`UploadDeck.js`, `MixingConsole.js`, `MasteringConsole.js`, `LearningHub.js`, `ChatInterface.js`, `Gateway.js`, `MixingTools.js`).
- **`utils/`**: Legacy audio engines and DSP modules (`AudioEngine.js` Tone.js engine, `DSP.js` wave-shaper).
- **`context/`**: Legacy state contexts (`ProjectContext.js`).
- **`misc/`**: Loose widget components and CSS modules (`Knob.js`, `VstContainer.js`, `ToggleSwitch.js`, etc.).
- **`HEROPAGES/`**: Early HTML landing page prototypes.
